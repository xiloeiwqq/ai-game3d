# AI WORLD GENERATOR

Полноценная 3D-игра на **Godot 4.7.2**, которая превращает текстовое описание в проверенный игровой мир. Игрок исследует локацию от первого лица, собирает три предмета и активирует выход.

Проект работает в трёх явно разделённых режимах:

- **ИИ • LLM API** — описание отправляется реальному OpenAI-compatible API, модель возвращает структурированный JSON;
- **Офлайн • алгоритм** — детерминированный процедурный генератор анализирует слова описания без сети;
- **Демо • пресет** — один из пяти готовых JSON-миров для мгновенной демонстрации.

Офлайн-режимы не выдаются за ИИ-генерацию: активный режим всегда указан в интерфейсе.

## Быстрый запуск

### Готовая Windows-сборка

Запустите:

```text
build/windows/AIWorldGenerator.exe
```

Либо дважды щёлкните `run_game.bat`: он сначала ищет готовую сборку, затем установленный Godot.

### Из исходного проекта

1. Установите **Godot 4.7.2 stable**.
2. Импортируйте `project.godot` через Project Manager.
3. Нажмите **F6/F5** или выполните:

```powershell
godot4 --path .
```

Минимальные требования: Windows 10/11 x64, видеокарта с OpenGL 3.3, 4 ГБ RAM. Проект использует GL Compatibility renderer.

## Как создать первый мир

1. В главном меню нажмите **«СОЗДАТЬ МИР»**.
2. Введите произвольное описание длиной от 12 символов, например:

   > Создай зимний замок среди чёрных сосен, с разрушенными башнями, магическими кристаллами и древними воротами.

3. Без API выберите **«ОФЛАЙН • АЛГОРИТМ»**. При настроенном API доступен режим **«ИИ • LLM API»**.
4. Выберите тему, размер, сложность и плотность декораций.
5. Нажмите **«СГЕНЕРИРОВАТЬ МИР»**.
6. Найдите три светящихся предмета. После счёта `3/3` портал активируется — войдите в него для победы.

Для мгновенного запуска откройте **«ПРИМЕРЫ МИРОВ»** и выберите один из пяти пресетов.

## Подключение реального LLM API

Ключи не хранятся в проекте и не включаются в сборку. Перед запуском задайте переменные окружения:

```powershell
$env:AI_WORLD_API_URL = "https://api.openai.com/v1/chat/completions"
$env:AI_WORLD_API_KEY = "ваш-секретный-ключ"
$env:AI_WORLD_MODEL = "gpt-4o-mini"
./build/windows/AIWorldGenerator.exe
```

Поддерживается OpenAI-compatible формат `chat/completions`, в том числе локальные серверы:

```powershell
$env:AI_WORLD_API_URL = "http://127.0.0.1:11434/v1/chat/completions"
$env:AI_WORLD_MODEL = "ваша-модель"
./build/windows/AIWorldGenerator.exe
```

Внешние незашифрованные `http://` адреса запрещены; HTTP разрешён только для `localhost`/`127.0.0.1`. Подробности: [`docs/API_SETUP.md`](docs/API_SETUP.md).

## Реализовано

- современное главное меню, конструктор, экран генерации, HUD, пауза, настройки и экран победы;
- FPS-контроллер на `CharacterBody3D`, капсульная физика, мышь, прыжок, бег и границы мира;
- 31 разрешённый процедурный 3D-ресурс с согласованными габаритами и коллайдерами;
- пять тем: волшебный лес, заброшенный замок, Марс, древний храм, ледяная пещера;
- пять готовых офлайн JSON-миров;
- строгая схема JSON 1.0 и whitelist всех `resource_id`;
- проверка типов, координат, поворотов, границ, количества и пересечений;
- BFS-проверка доступности трёх предметов и выхода с учётом footprint препятствий;
- ограниченная автопочинка непроходимой/небезопасной карты;
- реальная OpenAI-compatible интеграция, тайм-аут и до трёх попыток исправления ответа;
- безопасное сохранение созданных JSON и последних 20 описаний в `user://`;
- настройки громкости, мыши, полноэкранного режима и уменьшения анимаций;
- синтезированный звук сбора без внешних/фиктивных файлов;
- воспроизводимость офлайн-мира по описанию, параметрам и seed;
- release-сборка Windows с встроенным PCK.

## Честно зафиксированные ограничения

- Live-вызов внешнего LLM не выполнялся в тестовом окружении, потому что API URL/ключ не предоставлены. Парсер, prompt, whitelist, обработка ошибок и конфигурация протестированы локально.
- 3D-каталог создан процедурно средствами Godot, а не Blender/GLB: Blender отсутствовал в окружении. В проекте нет фиктивных ссылок на модели, и все визуальные ресурсы реально создаются игрой.
- Автоматические тесты выполнялись на Windows; другие платформы исходно совместимы с Godot, но готовая сборка подготовлена именно для Windows x64.

## Пользовательские данные

Godot хранит настройки, историю и созданные миры в:

```text
%APPDATA%\Godot\app_userdata\AI World Generator\
```

API-ключ туда не записывается.
