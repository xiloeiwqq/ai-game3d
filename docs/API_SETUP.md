# Настройка LLM API

## Переменные окружения

| Переменная | Обязательна | Назначение |
|---|---:|---|
| `AI_WORLD_API_URL` | да | OpenAI-compatible endpoint `chat/completions` |
| `AI_WORLD_API_KEY` | для внешнего API | Bearer-токен; локальный сервер может работать без него |
| `AI_WORLD_MODEL` | нет | модель; по умолчанию `gpt-4o-mini` |

Пример PowerShell:

```powershell
$env:AI_WORLD_API_URL = "https://api.openai.com/v1/chat/completions"
$env:AI_WORLD_API_KEY = "sk-..."
$env:AI_WORLD_MODEL = "gpt-4o-mini"
./build/windows/AIWorldGenerator.exe
```

Переменные, заданные через `$env:`, действуют только для текущего окна PowerShell и дочернего процесса игры.

## Локальная модель

Допустимы незашифрованные адреса только на loopback-интерфейсе:

```powershell
$env:AI_WORLD_API_URL = "http://127.0.0.1:11434/v1/chat/completions"
$env:AI_WORLD_MODEL = "qwen2.5:14b"
./build/windows/AIWorldGenerator.exe
```

Сервер должен принимать OpenAI-compatible тело:

```json
{
  "model": "...",
  "temperature": 0.65,
  "response_format": {"type": "json_object"},
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ]
}
```

И возвращать `choices[0].message.content` с JSON-объектом. Также поддерживается поле `output_text` или прямой объект мира.

## Проверка подключения

После запуска статус в главном меню должен измениться на **«AI API ГОТОВ»**, а в конструкторе станет доступен режим **«ИИ • LLM API»**.

## Надёжность

1. HTTP-запрос имеет тайм-аут 35 секунд.
2. Игра извлекает JSON, не исполняя текст/код модели.
3. Результат проходит строгую проверку схемы, whitelist, координат, пересечений и BFS.
4. При ошибке модели выполняется до трёх запросов с конкретными замечаниями валидатора.
5. После трёх неудач пользователь получает понятную ошибку и может повторить запрос.

## Безопасность

- Ключ читается только из окружения и не записывается в проект, сохранения или журнал.
- Разрешены `https://`, `http://127.0.0.1` и `http://localhost`.
- Модель не может передавать пути к файлам: `resource_id` сверяется с локальным каталогом.
- Ответ модели никогда не исполняется как GDScript.
- Внешний API получает пользовательское описание и параметры генерации. Не вводите секретные данные в описание мира.

## Если API недоступен

Выберите **«ОФЛАЙН • АЛГОРИТМ»** или один из пяти демо-миров. Эти режимы полностью играбельны без сети и явно обозначены как offline/demo.
